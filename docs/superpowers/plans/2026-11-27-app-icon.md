# App Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give MacSpace its own app icon (direction "C · Spicchio") as an Icon Composer `.icon`, and record the mark in the MacSpace design system.

**Architecture:** A small Python script draws the mark's SVG layers from the spec's geometry and writes the `.icon` bundle (`icon.json` plus `Assets/`), so the icon can be rebuilt instead of hand-edited. Xcode compiles the `.icon` as the app icon through `project.yml`. `ictool` renders previews for checking.

**Tech Stack:** Python 3 (stdlib only), Icon Composer `.icon` format, XcodeGen, Xcode 27 `ictool`.

**Spec:** `docs/superpowers/specs/2026-11-27-app-icon-design.md`

## Global Constraints

- The colors come only from the spec's Fusion table. Orange appears only in the wedge, hsl(16, 88%, 57%) in light and hsl(16, 85%, 56%) in dark.
- Geometry:
  - the ring's inner radius is 1/3 of its outer radius;
  - the ring is two arcs with a hairline gap;
  - the wedge is 56° at the top right, lifted outward along its bisector.
- The deployment target is macOS 27; nothing targets older systems.
- Commits are conventional with no attribution lines. The branch is `feat/15-app-icon`. Never commit `Local.xcconfig`.

## Review Focus

- **16 pt rendering:** the ring hole and the wedge gap must stay open and must not fill in. Check the 16 and 32 px `ictool` renders.
- **Dark appearance:** the dark ring tones must actually be used, not the light ones on graphite. Check the Dark rendition.
- **Tinted and clear renditions:** the wedge must still read as separate from the ring when color is gone. Check the TintedDark and ClearLight renders.
- **App bundle:** the built app must carry the icon. Check that `CFBundleIconName` is `AppIcon` in the built Info.plist, and that the Dock shows it on a fresh launch.
- **XcodeGen:** the `.icon` must survive `xcodegen generate` as one resource, not as loose files. Check that the build output has no `icon.json` copied into Resources.

### Task 1: Icon bundle from a reproducible source

**Files:**
- Create: `design/icon/make_icon.py`
- Create (generated, committed): `App/MacSpace/AppIcon.icon/icon.json` and `App/MacSpace/AppIcon.icon/Assets/*.svg`

- [ ] **Step 1:** Write `design/icon/make_icon.py <out.icon>`.
  - It draws, on a 1024-point canvas, `ring.svg` (two arcs, light tones) and `ring-dark.svg` (dark tones), and `wedge.svg` with `wedge-dark.svg`.
  - It writes `icon.json` with:
    - the background fill as a sand gradient, specialized to graphite for `dark`;
    - one group holding the ring layer and the wedge layer on top, both glass;
    - dark image specializations for both layers.
- [ ] **Step 2:** Run it, then render the previews with `ictool` into the scratchpad:
  - macOS Default, Dark, TintedLight, TintedDark and ClearLight at 1024;
  - Default and Dark at 32 and 16.

  Expected: the mark is centered, the dark tones are used, and every rendition differs from Icon Composer's blank default.
- [ ] **Step 3:** Look at every render. Adjust the geometry only within the spec's ranges, until the 16 px render keeps the hole and the gap open.
- [ ] **Step 4:** Commit: `feat(app): MacSpace app icon (Icon Composer, light/dark)`.

### Task 2: Wire the icon into the app

**Files:**
- Modify: `project.yml` (target `MacSpace`: the `.icon` as a resource, and `ASSETCATALOG_COMPILER_APPICON_NAME: AppIcon`)

- [ ] **Step 1:** Make the edit, run `xcodegen generate -q`, then do a Debug build with `-quiet`. Expected: exit 0 and no warnings.
- [ ] **Step 2:** Check the result:
  - `CFBundleIconName` is `AppIcon` in the built app's Info.plist;
  - `Assets.car` (or the icon output) is present;
  - no loose `icon.json` sits in Resources.
- [ ] **Step 3:** Launch our own instance with `open -n -g`, back up the defaults, and quit only our own PID. Capture the Dock and the About window if the screen is unlocked. Restore the defaults.
- [ ] **Step 4:** Commit: `build: compile AppIcon.icon as the app icon`.
